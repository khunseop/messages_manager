# MessageManager

회사 메신저 대화록(MHT) 백업 및 마크다운 변환 자동화 툴입니다. 
메모장을 활용하여 가시적인 방해 없이 텍스트를 추출하며, 중복 제거 및 날짜별 분리 저장을 지원합니다.

## 주요 기능
- **비가시적 추출**: 메모장을 화면 밖으로 숨겨 작업 중 방해 없이 MHT 텍스트 추출.
- **스마트 파싱**: 인라인 링크(`<a>`), HTML 엔티티(`&lt;`, `&gt;`) 처리 및 Obsidian 호환성 최적화.
- **자동 병합 및 분리**: 기존 데이터와 중복을 체크하여 병합하고, 대화방별/날짜별 마크다운 파일로 자동 분할 저장.
- **아카이브**: 처리가 완료된 원본 파일은 `archive` 폴더로 자동 이동하여 중복 작업 방지.
- **자동화 지원**: 윈도우 작업 스케줄러 등록을 위한 가이드 및 스크립트 제공.

## 설치 및 시작하기

### 1. 요구 사항
- **Windows OS** (메모장 및 win32 API 활용)
- **Python 3.x**

### 2. 의존성 설치
```bash
pip install -r requirements.txt
```

### 3. 초기 설정 (중요)
`setup.bat` 파일을 실행하여 초기 환경을 구축하세요.
- 입력/출력/백업 폴더 경로를 지정할 수 있습니다.
- 매일 자동으로 실행될 시간을 설정할 수 있습니다.
- 실행 후 `config.json`, `run_task.bat`, `register_task.bat` 파일이 생성됩니다.

### 4. 자동 실행 등록
`setup.bat` 완료 후 생성된 **`register_task.bat`**을 실행하면 윈도우 작업 스케줄러에 등록되어 매일 정해진 시간에 자동으로 변환 작업이 수행됩니다.

## 파일 구조
- `main.py`: 프로그램 진입점 및 전체 프로세스 제어.
- `parser_core.py`: MHT 추출 및 파싱 핵심 로직.
- `config.json`: 사용자 경로 및 실행 설정 저장.
- `setup.bat`: 사용자 맞춤 초기 설정 마법사.
- `build.bat`: 실행 파일(.exe) 빌드 스크립트.

## 주의 사항
- MHT 파일을 추출할 때 시스템 메모장을 일시적으로 활용하므로, 실행 중에는 메모장 창이 잠깐 나타났다 사라질 수 있습니다 (비가시적 모드 적용됨).
- 작업 스케줄러 등록 시 관리자 권한이 필요할 수 있습니다.
